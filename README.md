# Hail apps

Downloads for [Hail](https://hail.itayp2405.workers.dev): anime, shows and movies in one place. The apps block the video players' ads, pop-ups and redirects.

Get the latest version from [Releases](https://github.com/itay2405/hail-releases/releases/latest), or from the **Install** button on the Hail website.

| Device | How |
| --- | --- |
| Windows 10 / 11 | `Hail-Setup.exe` (installer) or `Hail-Portable.exe` (no install) |
| Android phone or tablet | `Hail.apk` |
| Android TV, Google TV, Fire TV | `Hail-TV.apk`, or in the Downloader app: `https://hail.itayp2405.workers.dev/downloads/hail-tv.apk` |
| iPhone and iPad | Apple only allows App Store apps. Open Hail in Safari → Share → **Add to Home Screen** |
| LG TVs (webOS) | `Hail-LG.ipk`, installed with LG Developer Mode: install the Developer Mode app on the TV, sign in with a free LG developer account, turn on Dev Mode and Key Server, then send the file from your computer with webOS Dev Manager. Or use Hail in the TV's web browser. |
| Samsung TVs (Tizen) | Samsung only installs outside apps signed for one specific TV, so use Hail in the TV's Internet app (it works with the remote), or a Google TV / Fire TV stick. |

Hail is invitation-only: request an invitation on the website, then sign in once approved.
